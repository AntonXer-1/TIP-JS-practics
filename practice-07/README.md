# Практическая работа № 7

Список задач на React. Вариант 1. Задачи меняются в памяти, после перезагрузки возвращается исходный набор.

```sh
npm ci
npm run dev
npm test
npm run build
```

При запуске активен фильтр «В работе» и видно 7 задач. После завершения задачи 4 осталось 6. Фильтр «Завершенные» на исходном наборе показывает задачи 1, 10, 16, 25 и 31. Сводка считает весь набор из 12 задач.
