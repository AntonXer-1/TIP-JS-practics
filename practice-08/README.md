# Практическая работа № 8

Вариант 1. React получает список и категории из учебного API. Фильтры передаются серверу. После успешного изменения список загружается повторно.

```sh
npm ci
npm run api
```

Во втором терминале из этой же папки — `npm run dev`. Другой порт API можно задать так: `npm run api -- 5508`, затем `VITE_API_URL=http://127.0.0.1:5508/api npm run dev`.

Первый запуск с фильтром «В работе» показал в консоли `true 0`, затем `false 7`. После переключения задачи 4 сервер вернул 6 задач, задача 4 исчезла из списка. Временный вывод был включён только в сборке для проверки.

`npm test` — 23 проверки API, 14 интеграционных и 15 проверок React, все прошли. `npm run build` выполнена.
