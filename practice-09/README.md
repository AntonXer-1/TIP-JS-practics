# Практическая работа № 9

Express-сервер для списка задач. Для КР3 добавлен `POST /api/tasks`. Валидный запрос создаёт задачу в памяти и возвращает 201. Пустое название отклоняется со статусом 400 и полем `error.details.title`.

```sh
npm ci
npm start
```

Сервер доступен по адресу http://127.0.0.1:5505/api. `GET /api/tasks?completed=false` для варианта 1 возвращает id 4, 7, 13, 19, 22, 28 и 34. Для сценария КР3 `GET /api/tasks?completed=true` возвращает id 1, 10, 16, 25 и 31, статус 200. После ошибочного POST запрос `GET /api/health` по-прежнему отвечает.

`npm test` — 92 проверки прошли. Проверка 405 для списка вызывает PUT, поскольку POST в КР3 стал разрешённым методом.
