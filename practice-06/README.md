# Практическая работа № 6

Браузерный клиент учебного API с серверной фильтрацией, добавлением, редактированием, переключением статуса и удалением задач. Вариант 1.

Из папки `practice-06` запустить `npm start` или `node tools/start.mjs`. Открыть http://127.0.0.1:5506/ или http://127.0.0.1:5506/?dataset=variant. Для запуска с другим API-портом выполнить `node tools/start.mjs 5515` и открыть http://127.0.0.1:5506/?api=http://127.0.0.1:5515/api. Для страницы проверок с этим портом используется тот же параметр `api` в `/checks.html`.

Контроллер перед показом списка запрашивает данные у сервера. После изменения задачи он повторяет запрос с текущими фильтрами. При смене фильтра прежняя загрузка отменяется, а ответ устаревшего запроса игнорируется. Состояния загрузки, пустого списка и ошибки показаны в интерфейсе.

В варианте 1 сервер вернул семь задач с `completed=false`. После переключения задачи 4 в Network появились `PATCH /api/tasks/4` со статусом 200 и `GET /api/tasks?completed=false` со статусом 200. В выборке остались id `[7, 13, 19, 22, 28, 34]`.

Проверки в Node.js v24.22.3 — `node checks/api-server.checks.js` (23/23), `node checks/modules.checks.js` (33/33), `node checks/integration.checks.js` (14/14). В Chromium страница `/checks.html` показала 14/14.
