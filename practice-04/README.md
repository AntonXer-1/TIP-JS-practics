# Практическая работа № 4

Форма создания и редактирования задач с валидацией и сохранением после перезагрузки. Вариант 1.

Из папки `practice-04` запустить `npm start` или `node tools/serve.mjs`. Общий набор доступен на http://127.0.0.1:5504/, индивидуальный — на http://127.0.0.1:5504/?dataset=variant. Внешних зависимостей нет.

После создания, редактирования, переключения статуса или удаления приложение сохраняет версию 1 и массив задач в localStorage. Ключ зависит от набора. Сброс удаляет только сохранение открытого набора. При недоступном хранилище или повреждённой записи приложение запускается с копией исходного набора и показывает сообщение.

Проверки в Node.js v24.22.3 — `node checks/service.checks.js` (35/35) и `node checks/modules.checks.js` (27/27). В Chromium страница `/checks.html` показала 23/23.

В общем наборе добавлена задача 20 «Изучить localStorage» с приоритетом high. После перезагрузки задача осталась на экране и в значении ключа `tip-js-practice-04:demo`. В индивидуальном наборе после добавления 75, редактирования 23 и удаления 37 сохранились id `[11, 23, 41, 58, 64, 75]`, название задачи 23 «Согласовать план проекта» и прогресс 0.0%. Сброс вернул исходные шесть задач.
